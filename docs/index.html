Everything you need for seamless high-speed file transfers.

16-Connection Parallel Engine

Splits direct HTTP/HTTPS downloads into concurrent range-requested chunks for max ISP bandwidth saturation.

🎥

YouTube Video & Playlist

Extract 4K, 1080p, 720p, or Audio-only formats with automatic 16-fragment concurrent downloading.

🧲

BitTorrent & Magnet Swarm

Integrated magnet loader with DHT, Transmission peer-ID spoofing, and automatic high-speed tracker injection.

💾

Smart Disk Inspector

Checks target drive space (`GetDiskFreeSpaceExW`). If C:\ is low on space, it automatically prompts you to switch to D:\.

📊

Sleek Animated UI

No noisy screen clutter! Renders clean single-line progress bars with live speed, byte counts, and seeder metrics.

📜

History & CSV Export

Automatically records all downloads, elapsed timings, and paths. Export logs to escaped CSV anytime.

Get Started in Seconds

Clone the repository and launch FetchDesk with Cargo.

git clone https://github.com/JOJINJOHN/fetchdesk.git
cd fetchdesk-src
cargo run

Optional Prerequisites

Install helper tools to enable YouTube quality extraction and BitTorrent functionality.

yt-dlp (YouTube Engine)

Extracts YouTube videos, formats, and playlists.

pip install -U yt-dlp

aria2 (BitTorrent Engine)

Drives magnet links and torrent file transfers.

winget install aria2.aria2

ffmpeg (Media Merger)

Combines separate video and audio format streams.

winget install Gyan.FFmpeg
