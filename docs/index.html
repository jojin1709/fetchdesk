Engineered for High Throughput & Efficiency

Everything you need for clean, accelerated command-line file downloads.

16-Connection Parallel Engine

Streams direct HTTP/HTTPS downloads concurrently over 16 split connections for maximum network bandwidth usage.

YouTube Video & Playlist

Download 4K, 1080p, 720p, or Audio formats with automated fragment connection acceleration.

BitTorrent & Magnet Swarm

Integrated tracker loader injecting active tracklist feeds, DHT, and client spoofing for prioritised download speeds.

Smart Disk Inspector

Performs dynamic local disk space inspection (`GetDiskFreeSpaceExW`). Switch output targets if the default path runs out of space.

Sleek Animated UI

Monitors active segments and downloads without cluttering your screen. Displays ETA, speeds, and status in real-time.

History Log & CSV Export

Maintains a persistent record of files, sizes, speeds, and timestamps. Supports seamless CSV exporting.

Chrome & Edge Extension

Instantly send links and YouTube videos directly to your local FetchDesk queue via context menu items or manual popup inputs.

Optional Helper Tools

Enable YouTube video processing and torrent capabilities. The PowerShell installer handles these automatically, or configure manually:

yt-dlp (YouTube Engine)

Handles video and audio stream extraction.

pip install -U yt-dlp

aria2 (BitTorrent Engine)

Backs BitTorrent links and magnet downloader workflows.

winget install aria2.aria2

ffmpeg (Media Merger)

Stitches separate HD video and audio formats together.

winget install Gyan.FFmpeg
